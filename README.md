# Portfolio d'Emmie

Site statique (HTML/CSS/JS) hébergé sur GitHub Pages.

## Arborescence

```
├── index.html          Accueil
├── projets.html        Liste des projets
├── a-propos.html       À propos
├── contact.html        Contact
├── projets/            Pages de détail des projets
├── assets/
│   ├── css/style.css   Styles (variables couleurs/polices en haut)
│   ├── js/main.js      Scripts
│   ├── images/         Images du site
│   └── fonts/          Polices
└── design/             Exports des maquettes Figma (référence)
```

## Voir le site en local

Ouvrir `index.html` dans un navigateur.

## Mise en ligne

Settings → Pages → Source : branche `main`, dossier `/ (root)`.
